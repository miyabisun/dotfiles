# Agent Talk

agent-talk は、人間が Tailscale/HTTPS 経由で Herdr 内の対象セッションへ
メッセージを原文で送る入口である。返答は、その CLI の会話履歴から読む。
Codex と Claude Code の同じ対話セッションで、外出先から帰宅後まで作業を続ける。

届いた人間の指示は、進行中の依頼と既存の授権に合わせて扱う。追加指示なら
元の目的と未完了の作業を保持して反映する。別の AI に文面や授権を判定し直させない。

返答・進捗・完了報告は、このセッションの通常の応答へ書く。ブラウザはその履歴を
読むため、専用の返信コマンドや別の記録への転記は要らない。送信の受付だけで
作業の完了を報告せず、実際に行ったことと残る作業を伝える。

対象の識別・配達状態・切断時の表示は daemon とブラウザが担う。受信側で
受領確認の巡回や再送を作らない。エージェント間の相談・委譲には使わない。
