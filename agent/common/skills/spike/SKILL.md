# spike

[共通契約](../deliver/CONTRACT.md) に従い、ユーザーが実際に試せる体験を作る。

1. 何が動けば試せるかを達成条件にする。既存 template が適合すれば使う。
2. knowledge のテスト戦略を読み、未定なら測る挙動と副作用の隔離方法を決める。
   再利用する新しい戦略は knowledge に残す。
3. 必要最小限を実装し、テストに加えて実際の起動・操作で体験を確かめる。
4. 共通契約のレビュー・指摘修正・commit を行い、動いた体験と残る制約を報告する。

将来の拡張だけの機構は足さず、動作に必要な不具合は「試作だから」で残さない。
license・version・公開方法は project と依頼に従う。
