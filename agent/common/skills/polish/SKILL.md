# polish

[共通契約](../deliver/CONTRACT.md) に従い、既存の体験を保ちながら不満を解消する。

1. knowledge の関連判断・テスト戦略を読む。不具合は再現し、望む挙動と守る既存挙動を達成条件にする。
2. 他者の変更を保護し、必要な範囲を修正する。必要なら設計も変える。
   無関係な dirty file や変更規模の増加だけで停止しない。
3. 影響する挙動の回帰を検証し、共通契約のレビュー・指摘修正・commit を完遂する。

Markdown は意味と参照の整合を確認し、形式 validator があれば使う。字面を固定するテストは作らない。
