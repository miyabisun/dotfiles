# refactor

[deliver](../deliver/SKILL.md) を、外から見える挙動を保つ制約で進める。
処理経路と呼び出し元を追い、入力・出力・エラー・順序・副作用の守る挙動を決める。
既存テストを再利用し、未検証の挙動は変更前にテストを補う。
既存機能とPonytail fullで整理し、同じ挙動を検証する。

不要な仕様を見つけたら根拠と影響を添えて `slim` の候補として報告する。
挙動維持の依頼を勝手に仕様削減へ広げない。削減目標や別の監査工程は作らない。
