# deliver

新しい体験・未稼働のものは `spike`、既存の改善は `polish`。指定があれば従い、迷ったら polish。
選んだ段階と [共通契約](CONTRACT.md) だけを読む。
担当は成果まで引き受け、必要ならサブエージェントへ分担する。
この skill は local commit までを授権する。依頼済みの後続工程は対応 skill で続ける。
外側が独立レビューを所有すると明示した場合だけ [PROCESS.md](PROCESS.md) を読む。
