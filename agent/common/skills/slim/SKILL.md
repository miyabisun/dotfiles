# slim

[deliver](../deliver/SKILL.md) を、依頼範囲で仕様を削減できる条件で進める。
実装・利用経路・配備を読み、残す用途・挙動・データと、廃止する機能・手順を定める。
参照がないだけで未使用と決めず、用途や影響が実際に不明な点だけ確認する。
対象と、それだけを支える依存・設定・テスト・文書を一緒に整理する。
残す挙動と意図した削減後の動作を検証し、廃止した仕様をテストのためだけに残さない。

必要なデータ保全・移行・復旧は維持し、無関係なテスト失敗を削除で隠さない。
セキュリティの削減は `knowledge-read` で解決した公開範囲別ポリシーと実際の経路に照らす。
古い規則や過去のagent判断を削除できない理由にせず、削減目標や専用の承認工程は作らない。
